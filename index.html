🛠️ Firebase 연결하기

기존 프로젝트 jangggimaster 를 같이 씁니다. 세 줄만 채우면 끝입니다.

1. 프로젝트 설정 → 일반 을 열고 맨 아래 내 앱 칸을 봅니다.
2. 웹 앱(</>)이 없으면 앱 추가 → 웹 으로 하나 만듭니다. (닉네임만 적으면 됩니다)
3. SDK 설정 및 구성 → 구성 에 나오는 apiKey · messagingSenderId · appId 를 복사합니다.
4. 이 폴더의 config.js 를 열어 그 세 줄에 붙여넣고 저장 → 새로고침.

규칙(Rules)은 손댈 것이 없습니다. 지금 규칙이 모든 문서를 허용하고 있어 이 앱이 쓰는 inventory_items · inventory_photos · inventory_sales 도 그대로 됩니다. 기존 데이터와 이름이 겹치지 않으니 섞이지도 않습니다.

자세한 설명은 폴더 안의 README.md 에 있습니다.
